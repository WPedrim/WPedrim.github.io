## Daily Rewards Script for ESX Legacy

A complete daily rewards system for ESX Legacy servers with a beautiful ox_lib interface.

### Features
- 7-day reward cycle with configurable rewards
- Beautiful ox_lib user interface
- Database storage for player progress
- Optimized for low resource consumption
- Easy configuration system
- Automatic progress reset after missed days

### Quick Start
1. Download the `daily_rewards` folder
2. Import the SQL file into your database  
3. Add to your server.cfg: `ensure daily_rewards`
4. Players can use `/dailyrewards` or press F7

### Requirements
- ESX Legacy Framework
- ox_lib
- oxmysql
